Evaluation Methodology & Mathematical Definitions

The Voice of India benchmark calculates Diarization Error Rate (DER) according to the strict NIST/pyannote.metrics specification:

DER = (T_miss + T_false_alarm + T_speaker_confusion) / T_reference * 100%

Key Protocol Rules:

  • Zero Collar (Strict Track): No tolerance collar is applied around speaker transitions. Every turn boundary and backchannel vocable counts.
  • Standard Collar (0.25s Track): A 250ms window centered on boundaries is excluded from scoring to accommodate human annotation jitter.
  • Overlapping Speech: Evaluated 100%. Multiple concurrent speakers are simultaneously evaluated.
  • Optimal Permutation: Speaker labels are mapped to reference identities via the Munkres / Hungarian linear sum assignment algorithm.
  • Bootstrap Confidence Intervals: 95% CIs are computed using 10,000 non-parametric bootstrap resamples across test sessions.
